Works without a key

The scenario logic is deterministic

Each Scenario profile fixes queries, expected messages, fallback root cause, affected services, remediation type/target, and recommendation. Hypothesis ranking uses textual overlap. generate_root_cause selects among three fixed candidates. The graph, Approval branch, HTTP targets, and recovery payloads never come from a model.

One influence point

The optional model refines one sentence

Correlation serializes the three Evidence lists into a prompt: “State one concise root cause… Do not propose an action.” LLMClient.complete returns provider text when successful or the Scenario fallback when disabled, empty, invalid, timed out, or otherwise failing.

Model may influence

root_cause wording, which also becomes the Approval reason and Report root cause.

Model cannot influence

Topology, tool selection, approval authority, action type, target, payload, or branch routing.

Direct HTTP

OpenAI and Gemini share a tiny adapter

OpenAI calls /v1/responses with gpt-5-mini; Gemini calls generateContent with gemini-2.5-flash. Settings decides whether a provider is enabled. Runtime settings replace the workflow’s LLM client, and API responses reveal only whether a key is configured.

Interview assessment

This is bounded augmentation, not autonomous reasoning

The design gains repeatability, offline operation, and a small blast radius for model failure. It loses open-ended investigation: queries and hypotheses already know the three lab Scenarios. Also, model output is accepted as an arbitrary string without structural validation or evidence citations.

Say: “The agent architecture is real orchestration, while the current LLM role is intentionally narrow. The project demonstrates stateful coordination and human control more strongly than autonomous diagnostic discovery.”

Which behavior may the optional LLM change?

Teach it back

Answer: “Can SREs work with no model, and is it still an agent system?”

Model answer
Yes. Scenario profiles, tools, graph state, evidence fan-out, correlation heuristics, approval, and reporting are deterministic. A model only refines root-cause wording. It remains an agent-oriented orchestration because specialist nodes coordinate through shared state and tools, but it is not an autonomous model-led investigator.
