Composition root

create_app wires replaceable dependencies

At startup, lifespan chooses Mongo or in-memory Store, chooses matching checkpoint storage, creates EventHub and InvestigationWorkflow, and attaches them to app.state. At shutdown it cancels tracked tasks and closes database clients. Passing Settings and Store directly makes API tests independent of Docker.

Contract map

Use the full API cheatsheet. The central split is: commands change simulation or execution; queries aggregate durable records; the stream exposes transient events; system/settings routes operate the lab.

202 semantics

Start validates, causes a failure, then returns an ID

  1. Reject duplicate active Scenario

    The API scans current Investigations and returns 409 for investigating/awaiting approval.

  2. Enable the failure

    Network failure becomes 503 outside test mode.

  3. Create records and optional task

    auto_start_investigation controls whether execution starts.

  4. Return 202

    The Investigation continues after the HTTP response.

Edge case

With auto-start false, the record is still stored as investigating, so it blocks another same-Scenario start until cancelled.

Streaming response

SSE is an async generator over EventHub

The route first verifies the Investigation. It then waits at most 15 seconds for each event, emits JSON frames, sends keep-alive comments on timeout, and stops when the request disconnects. CORS permits the two local frontend origins.

Local-lab controls

Settings and recovery are convenient, not production administration

Settings mutate one in-process object and rebuild the LLM client; keys are not echoed but are accepted over HTTP and not persisted. /system/recover fires all disable/rollback calls and reports success if any call succeeds. /system/status hardcodes MongoDB healthy and infers Redis/Postgres from sample API health.

What does the simulation route’s 202 mean?

Teach it back

Explain why create_app(settings, store) is the most important backend test seam.

Model answer
It is the composition root. Tests inject deterministic settings and InMemoryStore; lifespan then also selects InMemorySaver and avoids MongoDB. The same routes and workflow code execute, while external infrastructure and production configuration are replaced at one boundary.
