Two address spaces

Browser localhost is not container localhost

The browser reaches host-published ports such as localhost:8000. Inside the Compose network, backend reaches prometheus:9090, loki:3100, and sample-api:8001 through service-name DNS. Host port overrides do not change these internal addresses.

Health gates

depends_on orders readiness, not business correctness

Sample services wait for Redis, PostgreSQL, and Loki. Backend waits for MongoDB, observability, and both sample services. Frontend waits for backend health. Health checks prove endpoints/processes respond; they do not prove telemetry is warm, which is why the workflow separately waits ten seconds by default.

Named volumes

Four services persist data across ordinary shutdown

Prometheus, Loki, MongoDB, and PostgreSQL have named volumes. Redis does not. docker compose down keeps volumes; down -v intentionally removes them. Sample failure flags live only in process memory and reset when those containers restart.

Builds

Backend and samples use Python 3.11; frontend is multi-stage

Backend installs dependencies and runs Uvicorn. Both sample services share one image and choose their port/role from environment. Frontend installs, builds standalone Next output, copies only runtime artifacts, and runs as a non-root nextjs user.

Developer surface

The Makefile is intentionally small

make install prepares host dependencies. make test runs backend and frontend suites. make smoke validates Compose syntax and runs the workflow test—it does not boot the nine-service stack. make up/down wrap Compose.

Configuration detail

tools.py reads cached global Settings, while InvestigationWorkflow also receives a Settings instance. In Compose both derive from the same environment; custom test instances do not automatically redirect tool URLs.

How does backend reach Prometheus internally?

Teach it back

Explain why changing PROMETHEUS_HOST_PORT does not require changing PROMETHEUS_URL inside backend.

Model answer
The host mapping controls how a host process reaches the container. Backend is another container on incident-response-net, so it uses Compose DNS and Prometheus’s container port: http://prometheus:9090. That address is independent of the host-published port.
