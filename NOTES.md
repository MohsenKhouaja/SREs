# Teaching Notes

## Learner profile

- Software engineer with CRUD application experience.
- Has not yet read the project code.
- Has not previously used AI agents, LangChain, LangGraph, Python, or FastAPI.

## Teaching preferences

- Keep every explanation anchored to SREs's files, runtime behavior, and interview questions.
- Introduce framework and language mechanics only at the moment the project requires them.
- Use CRUD analogies as a bridge, then retire the analogy where it becomes inaccurate.
- Favor short lessons, code-reading trails, diagrams, retrieval questions, and teach-back prompts.
- Do not present generic documentation-like surveys.
- The learner prefers the complete curriculum to be generated up front, then studied at their own pace.

## Course direction

The full course is generated up front. It starts with one end-to-end incident lifecycle, then deepens one seam at a time: topology, shared state, graph execution, evidence tools, LLM boundaries, approval/checkpoint safety, persistence and live events, API behavior, frontend synchronization, sample telemetry, runtime packaging, testing, architectural critique, and interview defense.
